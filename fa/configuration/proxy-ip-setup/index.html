    راه‌اندازی Proxy IP

    Proxy IP آی‌پی پشتیبانِ کلادفلری‌ای است که ورکر شما وقتی اتصال مستقیم به مقصد شکست خورد از طریق آن خارج می‌شود. ورکر همیشه اول مستقیم تلاش می‌کند؛ فقط وقتی آن شکست خورد (در شبکه‌های فیلترشده شایع است) از طریق آی‌پی پروکسی دوباره تلاش می‌کند. اگر لیست آی‌پی پروکسی خالی باشد، راه پشتیبانی نیست — اتصال با خطای ws closed: 1011 می‌میرد و در لاگ می‌بینید: Retry connection failed: no proxy IP configured.

    دیپلوی تازه هیچی ندارد

    دیپلوی جدید با حالت Proxy IP شروع می‌شود ولی لیست آی‌پی‌ها خالی است. در شبکه‌ای که اتصال مستقیم شکست می‌خورد، یعنی هر اتصالی سر قدم پشتیبان می‌میرد. این شایع‌ترین دلیل «کار نکردن» نصب تازه است. اگر خطای بالا را می‌بینید، راه‌حل همین صفحه است.

    ببینید چی دارید

    پنل را باز کنید و بروید به صفحهٔ Proxy IP (یا در مرورگر به آدرس ورکرتان با پسوند /proxy-ip بروید). آنجا لیست آی‌پی‌های پروکسی بر اساس منطقه و اپراتور هست و می‌توانید تأخیر TCP از ورکر تا هر آی‌پی را تست کنید، تا آن‌هایی را بردارید که واقعاً از سمت اینترنت شما سریع‌اند.

    اپ RayZen Companion خودش این را چک می‌کند: قبل از شماره‌گیری از پنل می‌پرسد آی‌پی پروکسی تنظیم شده یا نه. اگر لیست خالی باشد، قبل از خراب‌شدن تونل می‌ایستد و دکمه‌ای مستقیم به صفحهٔ Proxy IP پنل می‌دهد.

    اضافه کردن آی‌پی پروکسی (دو راه)

    راه اول — داشبورد Cloudflare (پیشنهادی)

    متغیر محیطی RAYZEN_PROXY_IPS را روی ورکر بگذارید، هر آی‌پی در یک خط:

    RAYZEN_PROXY_IPS=203.0.113.10
203.0.113.11

    وقتی این متغیر خالی نباشد، در زمان اجرا جایگزین لیست آی‌پی‌های ذخیره‌شده در پنل/KV می‌شود. این راه پیشنهاد می‌شود چون عوض کردن Proxy IP از طریق پنل نیاز دارد بعدش اشتراک را به‌روز کنید — و کاربرانی که اشتراک فعال ندارند نمی‌توانند به‌روزش کنند، که کانفیگ‌های اهدایی را خراب می‌کند. متغیر محیطی هیچ‌کدام از این دردسرها را ندارد. بعد از تغییر، دوباره دیپلوی کنید (یا صبر کنید اعمال شود).

    راه دوم — تنظیمات پنل

    فیلد Proxy IPs / Domains را در تنظیمات پنل ویرایش کنید، هر ورودی در یک خط، بعد اشتراک را به‌روز کنید. فقط برای استفادهٔ شخصی که همهٔ کلاینت‌ها دست خودتان است.

    آی‌پی خوب انتخاب کنید

    • آی‌پی‌های منطقه و اپراتور خودتان را ترجیح بدهید — تست تأخیر صفحهٔ /proxy-ip می‌گوید کدام‌ها از سمت ورکر سریع‌تر جواب می‌دهند.
    • بیش از یکی بگذارید. یک آی‌پی پروکسی تنها ممکن است بی‌خبر از کار بیفتد؛ با چندتایی، ورکر می‌چرخد و مردن یکی شما را آفلاین نمی‌کند.
    • اگر برای همهٔ مقصدها (نه فقط آدرس‌های کلادفلر) آی‌پی ثابت می‌خواهید، به‌جایش از Chain Proxy استفاده کنید — آی‌پی خروجی را برای همهٔ هدف‌ها ثابت می‌کند. ببینید: صفحهٔ VLESS / Trojan.

    Proxy IP یا NAT64

    از نسخهٔ 3.4.2 پنل می‌گذارد بین حالت Proxy IP و NAT64 Prefix برای آدرس‌های CDN کلادفلر انتخاب کنید. Proxy IP پیش‌فرض است و همان چیزی است که بیشتر آدم‌ها می‌خواهند. پیشوندهای NAT64 مخصوص منطقه و اپراتورند — فقط اگر پیشوند درست شبکهٔ خودتان را می‌دانید عوضش کنید.

    چک‌لیست علائم

    می‌بینید یعنی راه‌حل
    ws closed: 1011 در لاگ کلاینت ورکر موقع خروج به خطا خورده آی‌پی پروکسی اضافه کنید (همین صفحه)
    no proxy IP configured مستقیم شکست خورد و لیست پشتیبان آی‌پی پروکسی خالی است آی‌پی پروکسی اضافه کنید (همین صفحه)
    دیروز کار می‌کرد، امروز مرده مستقیم شروع به شکست کرده و تک آی‌پی پروکسی‌تان هم مرده چند آی‌پی بگذارید، یا به Best Ping سوییچ کنید
    بعضی سایت‌ها باز می‌شن، بعضی نه مستقیم برای بعضی هدف‌ها جواب می‌دهد؛ یک آی‌پی خراب توی لیست پشتیبان است در /proxy-ip تست کنید، مرده‌ها را عوض کنید
