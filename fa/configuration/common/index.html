    تنظیمات مشترک یا Common

    این بخش شامل تنظیماتی میشه که بین همه پروتکل‌ها، پنل، لینک‌های اشتراک و قسمت DNS over HTTPS مشترک هستن.

    Local DNS

    این DNS بیشتر برای مقاصد مسیریابی استفاده میشه و به‌صورت پیش‌فرض، سرور Local DNS از Google DNS استفاده می‌کنه.

    سرورهای DNS زیادی به‌صورت IP برای Local DNS در دسترسن، ولی می‌تونید از localhost استفاده کنید که از سرور DNS اپراتورتون استفاده می‌کنه و برای مسیریابی مناسبه.

    DNS ضد تحریم

    این سرور DNS برای قوانین مسیریابی تحریم‌ها استفاده می‌شه. سرور DNS پیش‌فرض Shecan هست. قبل از تنظیم قوانین مسیریابی، باید بررسی کنید که آیا این DNS از دامنه‌های مورد نظر شما پشتیبانی می‌کنه یا نه.

    راهنمایی

    سرور DNS می‌تونه به شکل IP (UDP DNS)، TCP DNS، DOT یا DoH باشه.

    Fake DNS

    می‌تونید Fake DNS رو فعال کنید تا تأخیر DNS کمتر بشه، ولی با احتیاط — ممکنه با بعضی برنامه‌ها سازگار نباشه یا با DNS سیستم تداخل ایجاد کنه. اگه از کارکردش مطمئن نیستید، فعالش نکنید.

    فعال‌سازی IPv6

    پنل به‌صورت پیش‌فرض برای پروتکل‌های VLESS و Trojan کانفیگ‌های IPv6 ارائه می‌ده. اگه اپراتورتون از IPv6 پشتیبانی نمی‌کنه، غیرفعالش کنید تا تعداد کانفیگ‌ها کم بشه و همچنین تنظیمات DNS و مسیریابی برای همه پروتکل‌های VLESS، Trojan و Warp بهینه بشن.

    Allow connections from LAN

    اگر این ویژگی رو فعال کنید، دیگران در شبکه شما (به عنوان مثال شبکه Wifi) می‌تونن با داشتن IP محلی دستگاه شما از پروکسی شما استفاده کنن. در اصل میتونن یه پروکسی socks روی دستگاه خودشون تنظیم کنن، IP محلی شما رو به عنوان آدرس و این پورت‌ها رو بر اساس برنامه‌ای که استفاده می‌کنید تنظیم کنن:

    • v2ray: 10808
    • sing-box: 2080
    • Clash: 7890

    لطفاً توجه داشته باشید که استفاده از این قابلیت در شبکه‌های اداری یا عمومی می‌تونه خطرناک باشه.

    Log Level

    سطح گزارش‌های برنامه رو مشخص می‌کنه. بصورت پیشفرض "warning" هست که برای اشکال‌زدایی مشکلات کافیه، با این حال ممکنه لازم باشه برای ثبت issue در Github یا بررسی دقیق فعالیت پروکسی تغییرش بدید.

    سازگاری کلاینت

    مشخص می‌کند کانفیگ‌های تولیدشده روی کدام نسل از هسته‌ی Xray اجرا شوند.

    همگانی (پیشنهادی) کانفیگ‌هایی می‌سازد که همه‌ی هسته‌های رایج می‌پذیرند: اینباند socks، قطعه‌بندی روی دایلر freedom و بدون تعیین حداقل نسخه. همین باعث می‌شود اشتراک شما در همان نسخه‌ی v2rayNG یا v2rayN یا Streisand یا Hiddify که همین حالا نصب دارید کار کند.

    فقط هسته‌های جدید از قابلیت‌های Xray 26 استفاده می‌کند (finalmask و happy eyeballs). هسته‌ای که این کلیدها را نشناسد کل کانفیگ را رد می‌کند، نه اینکه فقط آن کلید را نادیده بگیرد؛ نتیجه کانفیگی است که وارد می‌شود، وصل به نظر می‌رسد و هیچ سایتی باز نمی‌شود.

    Warning

    این گزینه را تنها وقتی انتخاب کنید که همه‌ی دستگاه‌هایتان هسته‌ی Xray به‌روز دارند.

    دامنه شخصی

    اگر دامنه شخصی روی اکانت کلادفلرتون دارید می‌تونید یه زیردامنه دلخواه ازش رو اینجا وارد کنید، به هیچ تنظیماتی در پنل هم نیاز نداره.

    کانفیگ‌های مربوط به این دامنه به همون لینک‌های اشتراکتون با نشانه D اضافه می‌شه.

    سرور DoH زیرساختی

    پنل یه DNS over HTTPS به شما میده که بصورت پیشفرض از DoH رسمی کلادفلر استفاده می‌کنه.

    شما از این قسمت می‌تونید اون DoH رو عوض کنید و مثلا از یه سروری مثل Adguard استفاده کنید که تبلیغات و بدافزار و ... رو هم مسدود کنید.

    مسیر پنل و لینک‌های اشتراک

    برای جلوگیری از دسترسی بات‌ها یا خزنده‌ها یک مسیر امن برای دسترسی به پنل و لینکای اشتراک دارید، از این قسمت می‌تونید تغییرش بدید.

    بعد از تغییر پنل شما رو به آدرس جدید پنل هدایت می‌کنه و باید لینکای اشتراک رو از اول بگیرید.

    دامنه پوششی یا Fallback

    بصورت پیشفرض درخواست‌های نامعتبر به ورکر شما پاسخ 404 برمی‌گردونن.

    می‌تونید این رفتار رو تغییر بدید و یه دامنه شناخته شده اینجا قرار بدید. فقط دقت کنید بعضی از آدرس‌ها درخواستای ورکر رو محدود کردن، بنابراین باید تست کنید.
