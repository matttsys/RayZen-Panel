از این بخش می‌تونید رمز پنل رو عوض کنید، پنل رو به آخرین نسخه پایدار به روز کنید یا برای همیشه از حساب خودتون حذفش کنید.

دکمه بروزرسانی تا وقتی فید انتشار RayZen وجود نداشته باشه غیرفعال می‌مونه — پنل نسخه‌ی خودش رو چک می‌کنه نه نسخه‌ی پروژه‌ی دیگه‌ای رو. وقتی فید منتشر شد، دکمه با انتشار نسخه‌ی جدید خودکار فعال می‌شه.
